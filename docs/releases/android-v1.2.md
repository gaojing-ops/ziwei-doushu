## 下载与升级

附件 `Ziwei-DeepSeek-1.2.apk`，约 6.5 MiB，Android 7.0 及以上，需正常更新的 Android System WebView。应用 ID 不变：`cn.local.ziweichart`；版本 1.2，versionCode 3；沿用此前调试签名，可覆盖 1.0/1.1 并保留已保存的 Key。不含自动更新或应用商店上架。

打开“DeepSeek 设置”，自行在手机填写 Key、阅读说明并保存，起盘后点击“开始解读”。排盘可离线；AI 需联网并按自己的账户计费，不内置真实 Key。此前已配置 Key 的用户可继续使用。
