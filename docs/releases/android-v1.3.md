## 下载与安装

下载附件 **`Ziwei-DeepSeek-1.3.apk`**，约 4.6 MiB，Android 7.0 及以上，需正常更新的 Android System WebView。应用 ID `cn.local.ziweichart`，versionCode 4，沿用此前签名，可覆盖 1.0／1.1／1.2 并保留设置。仍是调试签名的个人测试构建，无自动更新。

自己在手机“DeepSeek 设置”填写 API Key。排盘离线，主动发送 AI 请求才联网并按自己的账户计费；APK 不含真实 Key。包体缩小来自清理旧增量构建资源，课程索引仍为 1815 条。
