# 时间换日与运限切换修复

本地修改基于上游提交 `495b79ecb3524b20b2edc026067d7d0b0f407319`。

## 时间口径

- 表单预览、直接起盘、合盘与分享还原统一通过 `lib/ziwei/share.ts` 转换。
- 已选出生地：调用现有真太阳时模块，合并经度修正与均时差；未选出生地：保留北京时间。
- 先确定真太阳日及其时辰，再把晚子时按次日处理；统一使用 UTC 日期运算处理月末、闰年及年末进位。
- 保留 `origInput`，页面同时显示原始出生输入与实际排盘日期。
- 不知道时间时仍按原界面说明采用子时，不推断真实出生时辰。
- 夏令时与历史时区仍按原项目约定由用户确认标准时间；本次没有增加自动扣减。

## 运限切换

`/chart` 页面统一持有视图与流年年份，导航与命盘读取同一状态；移除盘面内部的第二套导航。重新起盘后重置为本命视图及当前年份。保留原有四化展示口径，本次未扩展新的运限算法。
